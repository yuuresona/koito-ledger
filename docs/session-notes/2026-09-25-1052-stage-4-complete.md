# Stage 4 monthly statistics completed

**Date:** 2026-09-25 10:52 CST

## Documentation and scope

- Recorded Stage 4 authorization before implementation and followed a red-green-refactor sequence with targeted tests after every increment.
- Finalized the previously provisional empty-child wording as `No subcategory` in the product specification.
- Kept the accepted text-only scope: no chart, dashboard cards, budget comparison, trend, dependency, database table, or persisted summary was added.

## Delivered

- Added an immutable `MonthlyStatistics` model that aggregates existing monthly transaction rows into income, expense, balance, level-2 totals, optional level-3 totals, and direct level-2 amounts using integer cents.
- Added two-decimal same-side percentage formatting with an explicit `<0.01%` result for smaller nonzero shares and no invalid division when a side total is zero. Percentage scaling uses `BigInt` intermediates so large valid monthly accumulations cannot overflow.
- Added a reactive `StatisticsRepository` projection over `TransactionRepository.watchMonth`, so creates, edits, deletes, category renames, and atomic category migrations refresh the same statistics stream.
- Replaced the Statistics placeholder with compact Material list rows for the three totals and separate Income and Expense hierarchies. `No subcategory` appears only for mixed direct/subcategory assignments; direct-only categories are not repeated.
- Added a shared integer-only CNY formatter and moved transaction-row currency formatting to it, eliminating floating-point conversion from display formatting.
- Preserved the shell-owned selected month across Transactions and Statistics, empty-month zero totals, retryable load errors, Android-first Material 3 layout, and centralized English localization strings.
